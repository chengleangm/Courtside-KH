# Confirmation Ticket Update

## Added

- Fully responsive confirmation card for 320px, 360px, 375px, 390px and 430px mobile screens.
- Customer name in the confirmation details.
- Digital ticket section with a **Save ticket image** button.
- High-resolution 1080 × 1600 PNG generation directly in the browser.
- Ticket content: reference, customer, phone, sport, court, date, time, duration, selected blocks, amount due, status and venue check-in instructions.
- English and Khmer text support.
- Native mobile share sheet when file sharing is supported.
- Automatic PNG download fallback on desktop and unsupported browsers.
- Matching implementation in the zero-install static demo.

## Privacy

The ticket is generated locally in the customer’s browser. No third-party screenshot or image-generation service receives the booking details.
