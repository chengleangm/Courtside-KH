# Courtside KH — Language, Admin Calendar & Editable Demo Bookings

## Added

- English / Khmer language switch on the customer website.
- English / Khmer language switch inside the admin dashboard and admin login.
- Khmer translations for the homepage, booking flow, timetable, enquiry form and confirmation screen.
- New admin **Booking calendar** view.
- Monthly calendar with booking counts displayed on each day.
- Clickable days with a customer booking schedule for the selected date.
- Admin **Edit booking** modal.
- Admin can edit customer name, phone, email, court, date, start time, duration, status and notes.
- Server-side overlap, operating-hour, blocked-period and price validation when an admin reschedules a booking.
- Eight realistic demonstration bookings for the customer presentation.
- Static zero-install demo updated with the language switch, admin calendar and editable bookings.
