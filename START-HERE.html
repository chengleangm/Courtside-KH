Courtside KH complete system V2

Booking, court management, calendar and check-in POS.

The full bilingual customer website and multipage administration system run through Next.js. Court details, galleries, rules, blocked times, customers, enquiries and reports are now included.

Run the full system

Open a terminal in this folder and run:

npm install
npm run dev

Then visit http://localhost:3000.

Admin login

Open:

http://localhost:3000/admin/login
